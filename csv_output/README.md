# CSV Output Directory

This directory contains extracted IRS 990 tables in CSV format with snake_case naming.

## File Naming Convention

All files follow the pattern: `{table_name}_{year}.csv`

Examples:
- `f9_p00_t00_header_2021.csv` - Form 990 Header for 2021
- `f9_p08_t00_revenue_2021.csv` - Form 990 Part VIII Revenue for 2021
- `f9_p07_t01_compensation_2021.csv` - Form 990 Part VII Compensation for 2021

## Column Naming

All column names are in snake_case format:
- `ein` - Employer Identification Number
- `taxpayer_name` - Organization name
- `tax_year` - Tax year
- `objectid` - Unique filing identifier
- `form_type` - Type of form (990, 990EZ, 990PF)

## File Format

- **Encoding**: UTF-8
- **Delimiter**: Comma (,)
- **Quote Character**: Double quote (")
- **Header**: First row contains column names
- **Line Ending**: Unix style (LF)

## Usage

### Python (pandas)

```python
import pandas as pd

# Read a specific table
df = pd.read_csv('f9_p08_t00_revenue_2021.csv')
print(df.head())

# Read with specific dtypes
df = pd.read_csv('f9_p08_t00_revenue_2021.csv',
                 dtype={'ein': str, 'tax_year': int})
```

### R

```r

library(data.table)

```

## Joining Tables

All tables can be joined using the `objectid` field:

```python
import pandas as pd

header = pd.read_csv('f9_p00_t00_header_2021.csv')
revenue = pd.read_csv('f9_p08_t00_revenue_2021.csv')

# Join on objectid
combined = header.merge(revenue, on='objectid', how='inner')
```

```r
library(dplyr)

header <- read.csv('f9_p00_t00_header_2021.csv')
revenue <- read.csv('f9_p08_t00_revenue_2021.csv')

# Join on objectid
combined <- inner_join(header, revenue, by = 'objectid')
```

## Notes

- Empty tables (no data for that year/form type) are not created
- Some tables only apply to specific form types (990 vs 990-EZ vs 990-PF)
- Schedule tables only exist for organizations that filed that schedule
- All financial amounts are stored as text - convert to numeric as needed

## Generated By

These files were created by `extract_all_tables.py` or `extract_all_tables.R`
from the ef2 library, extracting data from S3-hosted DuckDB databases.

For more information, see `EXTRACT_ALL_TABLES.md` in the parent directory.
